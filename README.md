# ColorWars 플러그인

색 순환 기반 PvP 정복 게임 (Paper 1.21.x)

## 규칙 요약
- 참가자는 각자 고유한 색을 배정받고, 색은 순환 구조(A→B→C→...→A)를 이룹니다.
- 게임 시작(`/colorwars start`) 시 모든 참가자를 x, z 각각 -3000~3000 사이의
  무작위 지점, 그 지점의 지표면(가장 높은 블록 바로 위)으로 순간이동시킵니다.
- 자신은 "다음 색" 플레이어(+그 부하)만 공격 가능, "이전 색" 플레이어(+그 부하)에게만 공격당함.
  (몹 데미지, 낙사 데미지 등 일반 데미지는 규칙과 무관하게 그대로 적용됨)
- 몹/환경 등 외부 요인으로 사망 → 그 자리에서 10초간 행동불가.
- 다른 플레이어에게 사망 → 그 플레이어의 부하가 되고 같은 색이 됨.
  - 부하였던 사람을 또 정복하면, 최종 정복자의 부하가 됨(팀 단위 승계).
  - 원래 부하를 거느리고 있던 리더가 정복당하면, 그 부하들도 전부 새 정복자 팀으로 넘어감.
- 부하의 최대 체력은 20 → 10 (항상 기존 체력 기준 절반, 누적 반토막 아님).
- 부하가 주인으로부터 50블록 이상 벗어나면, 이동은 막히지 않지만 벗어나 있는 동안
  1초마다 2데미지(1하트)를 계속 입습니다.
- 다이아몬드를 손에 들고 우클릭 → 액션바에 "다음 색" 플레이어의 방향과 거리 표시.
  사용할 때마다 다이아몬드 1개 소모(크리에이티브 모드는 예외).
- 엔더드래곤 알은 절대 블록으로 설치할 수 없음.
- 엔더드래곤 알을 오프핸드(왼손)에 들고 있으면 재생 I + 신속 II 효과가 계속 유지됨.
- 마지막 남은 리더가 모든 플레이어를 부하로 만들면 자동으로 게임 종료 및 승리 방송.

## 명령어
- `/colorwars register` - 다음 게임에 참가 등록 (플레이어)
- `/colorwars start` - 등록된 인원으로 게임 시작, 색 무작위 배정 (운영자, `colorwars.admin`)
- `/colorwars stop` - 게임 강제 종료 (운영자)
- `/colorwars status` - 현재 색 순환 및 부하 현황 확인

## 빌드 방법 (추천: GitHub Actions, 설치 아무것도 필요 없음)

1. https://github.com 에서 새 저장소(Repository)를 만듭니다. Public/Private 아무거나 상관없습니다.
2. 이 압축 파일 안의 내용물 전체(`pom.xml`, `src` 폴더, `.github` 폴더 등)를
   방금 만든 저장소에 업로드합니다.
   - 가장 쉬운 방법: 저장소 페이지에서 "Add file" → "Upload files" 클릭 → 압축을 풀어서
     나온 파일/폴더를 통째로 끌어다 놓고 "Commit changes".
   - `.github` 폴더도 반드시 같이 올라가야 합니다 (숨김 폴더처럼 보일 수 있으니 확인).
3. 업로드가 끝나면 저장소 상단의 **Actions** 탭으로 이동합니다.
   - 자동으로 "Build ColorWars Plugin" 워크플로우가 실행 중이거나 완료돼 있을 겁니다.
   - 안 보이면 왼쪽 목록에서 워크플로우를 선택하고 "Run workflow" 버튼을 눌러 수동 실행합니다.
4. 실행이 끝나면(초록 체크 표시) 해당 실행 결과 페이지 하단의 **Artifacts** 항목에서
   `ColorWars-jar`를 다운로드합니다. 압축을 풀면 `ColorWars.jar` 파일이 나옵니다.
5. 이 `ColorWars.jar` 파일을 호스팅 서버의 `plugins` 폴더에 업로드하고 서버를 재시작(또는
   재시작 없이 지원되는 경우 리로드)하면 끝입니다.

이후 규칙을 수정해달라고 요청하시면, 제가 소스를 고쳐서 다시 압축 파일로 드릴 테니
그걸 같은 저장소에 다시 업로드(덮어쓰기)하기만 하면 Actions가 알아서 새로 빌드해줍니다.

## 직접 로컬에서 빌드하고 싶다면 (선택)
이 컨테이너는 외부 Maven 저장소(repo.papermc.io)에 접근할 수 없어 여기서는 컴파일을
검증하지 못했습니다. 아래 순서로 직접 빌드해주세요.

1. Java 21, Maven 설치
2. 프로젝트 루트에서:
   ```
   mvn clean package
   ```
3. `target/ColorWars.jar` 를 서버 `plugins` 폴더에 복사

### 서버 버전이 1.21.1이 아니라면
`pom.xml`의 아래 부분을 서버의 정확한 마이너 버전으로 바꿔주세요.
(예: 서버가 1.21.4라면 `1.21.4-R0.1-SNAPSHOT`)

```xml
<dependency>
    <groupId>io.papermc.paper</groupId>
    <artifactId>paper-api</artifactId>
    <version>1.21.1-R0.1-SNAPSHOT</version>
    <scope>provided</scope>
</dependency>
```

## 구현 시 임의로 정한 부분 (규칙에 명시 안 됨, 확인 필요)
- 색 배정: `/colorwars register`로 등록한 인원을 `/colorwars start` 시점에 무작위 순서로 배정.
- 부하가 다른 사람을 죽여도, 그 전리품은 부하 개인이 아니라 "팀의 리더"의 부하가 됩니다
  (부하가 자기 부하를 따로 거느리는 구조는 만들지 않음).
- 리더가 정복당해 사라지면, 그 리더가 거느리던 부하는 전부 자동으로 새 정복자 팀에 편입됩니다.
- 다이아몬드는 소모되지 않고(=차감 안 됨), 그냥 손에 들고 우클릭하면 매번 방향을 알려줍니다.
- "외부요인 사망 후 그 자리에서 행동불가"는 이동 차단 + 슬로우/점프불가/실명 효과로 구현했고,
  전투(공격/피격) 자체를 막지는 않습니다. 필요하면 요청해주세요, 무적 처리도 추가 가능합니다.
- 엔더드래곤 알 효과(재생I+신속II)는 게임 참가자 여부와 무관하게 오프핸드에 들고 있는
  모든 플레이어에게 적용되도록 했습니다 (아이템 자체의 특성으로 판단). 게임 참가자에게만
  적용되길 원하시면 말씀해주세요.
